## Численная точность обратного ввода

ΔEOK измерен относительно исходного OKLCH в масштабе координат OKLab, где L находится в диапазоне от 0 до 1. Значения не умножены на 100.

Таблица 3. Ошибка на двух цветах внутри P3

| Цвет | P3 HEX | sRGB HEX, введённый как P3 | CSS OKLCH |
| :--- | :--- | :--- | :--- |
| Overlay | `0.00039569` | `0.00970827` | `2.87e-8` |
| Цвет из треда | `0.00092347` | `0.01927761` | `7.24e-8` |

CSS-ввод совпадает с исходным цветом в пределах float32. HEX-поле округляет каналы до байтов. Ошибку исходного цвета вне P3 нельзя устранить шестизначным HEX.

## Уточнения по ходу проверки

Первоначальный вопрос касался `background/overlay-base/theme` в файле Overlays 4. Первое чтение вернуло P3 HEX `#213062`; последующее чтение той же роли — `#1D2D6B` с другими ссылками на библиотечные переменные. Причина изменения состояния не устанавливалась. Эти наблюдения не считаются одной неизменной выборкой.

Для обратного опыта использован исходный OKLCH из локального токена `oklch(32.6% 0.117 266)`, а для прямого опыта — его округлённый P3 HEX `#1D2D6B`. Разница точности явно учитывается в расчётах.

Текст `oklch(...)` временно появился в Dev Mode после ввода в палитре прямой заливки. Повторение без MCP между вводом и обновлением показало переход к HEX и Display-P3 при сохранённом цвете.

## Ограничения отчёта

Версии Brave, macOS и сборки Figma в исходном прогоне не записаны. Для Node.js записано `v26.9.0`, для Color.js — `0.5.2`. Поле даты относится к часовому поясу Asia/Novosibirsk.

Проверка P3-профиля исходного прогона выполнена через UI; снимок самого меню тогда не сохранён. При обратном импорте локальной копии профиль проверен повторно и сохранён в [restored-profile.jpg](screenshots/restored-profile.jpg).

Исходная структура Overlay проверена через API, но отдельный полный архив исходного файла Overlays 4 не собран. Его переменные используются как контекст исходного вопроса, а воспроизводимые эксперименты размещены в тестовом файле.

Границы остальных утверждений описаны в [методике исследования](../../docs/research-methodology.md).
