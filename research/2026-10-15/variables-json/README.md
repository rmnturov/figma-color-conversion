# Проверка Variables JSON от 15.10.2026

Прогон исследует штатные **Export modes** и **Import mode**. Чтение чисел, исходные контрольные переменные и диагностические слои подготовлены через Plugin API. Экспорт и импорт выполнены через UI, включая **Save**, **Open** и **Replace** в диалогах macOS. [Выводы и методика](../../../docs/variables-json.md) описывают преобразования.

## Выполненный прогон

1. Зафиксированы переменные источника; обе коллекции экспортированы через **Export modes**.
2. Повторный экспорт десяти переменных сравнен с первой выгрузкой: JSON совпал. Файл пользователя `Mode 1.tokens.json` совпал с новой выгрузкой.
3. В обоих профилях созданы 52 переменные с контрольным RGBA `[0.03125, 0.0625, 0.125, 0.75]`.
4. Через **Import mode** импортированы 28 исходных записей и 24 контрольные записи.
5. Зафиксированы уведомления: 10 обновлённых; 18 обновлённых; 13 обновлённых и 11 пропущенных записей.
6. Созданы пять дополнительных переменных HSL в каждом файле.
7. HSL импортирован и экспортирован до обновления, без промежуточных Plugin API-вызовов.
8. После обновления повторены экспорт и чтение чисел.
9. Созданы связанные слои, проверены их количество и границы, сохранены локальные `.fig`.

В первом TXT-снимке P3 уведомление успело закрыться. Для его архивирования выполнены дополнительный импорт без сброса и контрольное повторение после сброса выбранной коллекции. Первый дал 9 обновлений и 11 ошибок; второй — 13 обновлений и 11 ошибок. Итоговые значения после обновления совпали с сохранённым снимком.

Это описание выполненного прогона. Инструкция повторения находится в документе Variables JSON. Неизменившееся контрольное значение подтверждает пропуск конкретной записи; одной общей ошибки импорта для этого недостаточно.

Чтобы проверить данные:

1. Выполните `npm ci` в корне репозитория.
2. Выполните `npm run verify:variables`.
3. Выполните `npm run check:links`.

Проверяются 28 исходных токенов, числа и алиасы, 24 случая в обоих профилях, пять HSL-случаев до и после обновления, 57 ID переменных и слоёв каждого документа, профили и SHA-256 копий.

## Границы

Промежуточные HSL-экспорты содержат RGB `1480` и `50`. Итоговые `.fig` хранят состояние после обновления. Для повторения промежуточного эффекта требуется заново импортировать HSL.

Проверяется обновление существующего режима. Перетаскивание JSON для создания переменных, прямой импорт ZIP, одновременный импорт нескольких режимов и другие типы токенов не проверялись. Обратный импорт новых `.fig` не выполнялся: проверены ZIP, `canvas.fig`, `fig-kiwi`, метаданные, CRC и SHA-256.

Brave: версия из установленного bundle. Версия Figma service build неизвестна. Экранная точность на физическом дисплее не измерялась. Численная модель не считается доказательством исходного кода импортера.
