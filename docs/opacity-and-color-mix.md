# Прозрачность группы и color-mix

Для одного непрозрачного SOLID-слоя обычное наложение группы с opacity `p` эквивалентно наложению того же цвета с альфой `p`, если базовый цвет, фон и режим смешивания совпадают.

Исходный вопрос касался `background/overlay-base/theme` внутри контейнера с `Opacity/Overlay` в [Overlays 4](https://www.figma.com/design/SR61SDd57O6FCtpj4Tbdu1/Overlays-4?node-id=1-16842).

## Проверенная структура

Через Figma Plugin API установлено:

- Контейнер **Opacity** содержит один прямоугольник **Fill**.
- Opacity контейнера составляет примерно `0.9`; погрешность соответствует float32.
- Opacity прямоугольника и SOLID-заливки составляет `1`.
- Заливка использует обычное смешивание **Normal**.
- Внутри контейнера отсутствуют текст, дополнительные заливки и эффекты.

Для этой структуры альфа итогового слоя равна `1 × 0.9 = 0.9`.

Шестизначный HEX в Variables или палитре не содержит альфу. Альфа переменной, opacity заливки и opacity контейнера относятся к разным уровням; RGB-код без этих значений и фона не определяет итоговый пиксель. Восьмизначный `#RRGGBBAA` включает альфу цвета, но не opacity родительской группы; его ввод через HEX в этом исследовании отдельно не проверялся. [Записи цвета и альфа](color-notations.md#альфа-и-выбор-источника-для-кода).

## CSS-представление

При значении `--kbq-opacity-overlay: 0.9` вычисление имеет следующий вид:

```css
background-color: color-mix(
    in srgb,
    var(--kbq-background-overlay-base-theme)
        calc(var(--kbq-opacity-overlay) * 100%),
    transparent
);
```

В `color-mix` применяется интерполяция с предумноженной альфой. У прозрачного второго цвета вклад в цветовые каналы равен нулю. После обратного деления на альфу исходные каналы сохраняются, а альфа умножается на долю первого цвета. [CSS Color 5](https://www.w3.org/TR/css-color-5/#color-mix).

Для цвета с собственной альфой `a` результат имеет альфу `a × p`. При `p = 0` цветовые каналы невидимы; деление на нулевую альфу для вывода канала не требуется.

`in srgb` задаёт пространство интерполяции, а не смешивание с фоном страницы. Вычисление цвета и последующее наложение на фон — отдельные операции. Для цветового сравнения учитываются поддержка охвата дисплея и поведение отрисовки.

## Различие областей действия

Opacity группы применяется к совместному результату её содержимого. Альфа `background-color` применяется к фону элемента. При добавлении текста, иконок, нескольких перекрывающихся слоёв, эффектов или blend modes эквивалентность одного слоя не переносится на всю группу. [CSS Color 4 об opacity](https://www.w3.org/TR/css-color-4/#transparency).

Проверка подтвердила структуру Figma и арифметику альфы. Отдельное сравнение пикселей браузерной отрисовки и Figma на одинаковом физическом дисплее не выполнялось.
